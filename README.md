# Retail Coffee Chain — Relational Database Project

## Project Overview

This project focuses on designing and implementing a centralized relational database for a growing retail coffee shop chain.

The goal is to organize data from different business sources and prepare structured datasets for operational reporting, payroll integration, and marketing analysis.

## Technologies

- PostgreSQL
- SQL
- pgAdmin 4
- MySQL
- phpMyAdmin
- IBM Skills Network Cloud IDE

## Database Design

The project covers the following entities:

- Staff
- Sales Outlet
- Sales Transaction
- Sales Detail
- Product
- Product Type

The schema uses primary keys, foreign keys, and normalized tables to organize business data and maintain referential integrity.

## Implementation

- Designed the database schema and ERD.
- Created database tables and relationships using SQL.
- Loaded project datasets into PostgreSQL.
- Created a view for staff and outlet information.
- Created a materialized view for product information.
- Prepared CSV exports for downstream database integration.
- Practiced importing data into MySQL using phpMyAdmin.

## Project Structure

- `ERD/` — Database diagrams and schema documentation.
- `Scripts/` — SQL scripts.
- `Data_Exports/` — Exported CSV files, when available.
- `Screenshots/` — Evidence of implementation and query results.

## Learning Outcomes

This project strengthened my understanding of relational database design, SQL, normalization, views, materialized views, data export, and cross-database data integration.
